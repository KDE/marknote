# Marknote 1.7 - The Editor Update

We have been working on the next release of Marknote for a few month now, and are happy to anounce what might be our biggest update yet.

## The Editor

Since the last release, our GSoC contributer [Prayag Jain](https://invent.kde.org/prayag) has done amazing work in completely rewriting the rich text editor. While previously using a default QTextDocument, we now have a fully fletched block editor like you might now from applications like Notion. Each element is now its own block, allowing quick re-aranging of your notes, and more importantly gives us full controll over the note rendering. For parsing the Markdown, we now use KDE's own markdown library [md4qt](https://invent.kde.org/libraries/md4qt), developed by [Igor Mironchik](https://invent.kde.org/imironchik) who has been a great help to us.

### Tables

![Table Editing](https://prayag2.github.io/posts/marknote-block-editor/table.gif)

Instead of fighting them, tables now offer intuitive controls for adding and editing rows and columns, and have much prettyer visuals, featuring a highlighted header row.

### Nesting and Drag and Drop

![Nested Lists and Drag and Drop](https://prayag2.github.io/posts/marknote-block-editor/drag-and-drop.gif)

The new editor offers full Markdown nesting, meaning you can have lists in quotes, code in quotes, code in lists and every possible combination of elements you can think of. We now thoughts don't work linearly, so of course you can rearange all the elements whenever your vision evolves.

Handeling the rendering ourselves, allows us to have beautifully themed quotes and native checkboxes.

### Code Blocks

![](anouncements/code_block_cpp.png)

Code blocks now offer beautiful syntax highlighting for most languages and allow you to quickly copy their contents.

For a more in depth read into how the block editor was made, we recomend Prayag's blogpost: [Meet Marknote's New Block Editor](https://prayag2.github.io/posts/marknote-block-editor/)

## UI

![](anouncements/toc.png) ![](anouncements/folders.png) ![](anouncements/style.png)

A lot of pollish was given to the rest of the application too: [Mathis](https://invent.kde.org/mbruchert) redesigned the Table of contents, to be quickly accessable by hovering on the side, or be pinned down next to the text, which can now be configured to be as wide or narrow as you want for easier readability.

In the last version, we started work on making it possible to sort your notes into sub folders. This is now fully working, enabeling you to add folders and drag and droping them arround to your liking.

You also now have the option to quickly configure how you want your notes to look without having to go to the settings. More in depth options are still accessable in the dedicated settings window.

## Bug fixes

[Partha P. G.](https://invent.kde.org/rugbedbugg), [Divyanshu Chandra](https://invent.kde.org/divyanshu) and others have put in a lot of work to fix the many bugs that still needed to be adressed before this release:

* Notes in subfolders are now acessable from the command bar (Partha P. G.)

* Images in the esitor don't get commicly large anymore (Partha P. G.)

* Marknote doesn't crash anymore when moving some notes (Partha P. G.)

* You don't get stuck anymore when editing tables if they are the last block (Divyanshu Chandra)

* Notes don't get dublicated anymore when renaming the currently open one (Divyanshu Chandra)

* You can not accidentaly override Notes anymore when switching between notebooks to quickly (Partha P. G.)

* and probably a lot more ...
